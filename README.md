# MNA Hub 1.1

Маленький сервер для MNA Launcher. Что он даёт:

- **Уникальные ники.** Ник закрепляется за аккаунтом (ник + пароль). Занять чужой нельзя, регистр букв не важен: `Alex`, `alex` и `ALEX` — один и тот же ник.
- **Друзья.** Заявки, список, статус «в сети» и «играет на сервере …».
- **Чат** между друзьями. История хранится на сервере, непрочитанные считаются, пока друг не в сети.
- **Приглашения в игру.** Друг нажимает «Играть», и лаунчер сам запускает Minecraft на нужном сервере.
- **Глобальный и локальный чаты.** Глобальный: все, кто в сети. Локальный: игроки, которые сейчас на одном и том же игровом сервере (определяется по статусу «играет на …»).
- **Уровни** (Обычный, Plus, Plus+, Pro, Admin): открывают оформление лаунчера и стильный ник в чатах. Выдаются кодами активации, командами администратора или запросом от платёжной системы.
- **Уровни (Обычный, Plus, Plus+, Pro, Admin)** с кодами активации: на них держится платное оформление лаунчера.
- **Три вида чата:** личный, глобальный (все игроки) и локальный (игроки на одном игровом сервере). Ник со стилем (шрифт, градиент, блеск) виден везде.
- **Прокси CurseForge** (по желанию). Ключ CurseForge лежит только на сервере и не попадает в `.exe`.

Работает на чистом Node.js 18+, без `npm install`. Данные лежат в одном файле `data/db.json`. Для компании друзей (до пары тысяч игроков) этого достаточно.

## Запуск

```
node server.js
```

Сервер слушает порт 8787. Проверка: открой `http://localhost:8787/health`.

Чтобы друзья подключались из интернета, нужен **https**: лаунчер отправляет пароль на этот адрес и откажется работать с обычным `http://` (кроме localhost и домашней сети). Самый простой путь: недорогой VPS и Caddy, который сам выпускает сертификат (см. `Caddyfile.example`). Запускать лучше как службу (`systemd`) или в Docker:

```
docker build -t mna-hub .
docker run -d --name mna-hub --restart unless-stopped -p 127.0.0.1:8787:8787 -v mna-hub-data:/data mna-hub
```

Если сервер стоит за Caddy/nginx, включи `TRUST_PROXY=1` (в Dockerfile уже включено), чтобы ограничения по IP работали по настоящему адресу игрока. Для nginx добавь `proxy_buffering off;`, иначе события чата будут приходить с задержкой.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `8787` | порт |
| `HOST` | `0.0.0.0` | на каком адресе слушать (`127.0.0.1`, если перед сервером стоит Caddy) |
| `DATA_DIR` | `./data` | где хранится `db.json` |
| `REG_CODE` | пусто | если задан, регистрация только по этому коду. **Рекомендую задать**, чтобы аккаунты не создавали посторонние |
| `CF_KEY` | пусто | ключ CurseForge (console.curseforge.com). Включает каталог CurseForge в лаунчере для всех вошедших игроков |
| `ADMIN_KEY` | пусто | секретный ключ владельца для HTTP-интерфейса администратора (выдача уровней и кодов из твоей платёжной системы). Без него интерфейс отключён |
| `TRUST_PROXY` | `0` | `1`, если сервер за обратным прокси |
| `MAX_USERS` | `5000` | предел числа аккаунтов |
| `REG_PER_HOUR` | `10` | сколько регистраций в час с одного адреса |
| `ADMIN_KEY` | пусто | секретный ключ для автоматической выдачи уровней и кодов (`/api/admin/...`). Без него эти запросы отключены |

Пример: `REG_CODE=мойкод CF_KEY=xxxx node server.js`

## Подключение лаунчера

Впиши адрес в `assets/edition.json` лаунчера **до сборки**, и у всех друзей всё заработает сразу:

```json
{"edition":"friends","featuredUrl":"","hubUrl":"https://hub.example.com","requireAccount":true}
```

`requireAccount: true` значит: играть без Microsoft можно только с аккаунтом MNA, то есть с уникальным ником. Адрес можно также вписать вручную в Настройках лаунчера.

## Уровни, цены и оплата

Цены и ссылки «Купить» лежат в `data/config.json` (необязательный файл; без него цены $0.99 / $2.99 / $4.99):

```json
{
  "currency": "USD",
  "prices": { "plus": 0.99, "plusplus": 2.99, "pro": 4.99 },
  "buyUrls": { "plus": "https://boosty.to/...", "plusplus": "https://...", "pro": "https://..." }
}
```

Ссылки должны начинаться с `https://`. Лаунчер показывает цену и кнопку «Купить» (она просто открывает ссылку в браузере). Сам Hub **деньги не принимает**: оплату принимает твой сервис, а уровень игроку включается одним из способов ниже.

**1. Коды активации.** Создаёшь коды, продаёшь или дарить, игрок вводит код во вкладке «Внешний вид». Код одноразовый и хранится на сервере только в виде хэша.
   - в чате лаунчера (админом): `/code plus 5`
   - в консоли при остановленном сервере: `node server.js code pro 3`
   - запросом: `curl -X POST https://hub.example.com/api/admin/code -H "X-Admin-Key: КЛЮЧ" -H "Content-Type: application/json" -d '{"tier":"plus","count":5}'`

**2. Автоматически после оплаты.** Платёжная система (или твой небольшой скрипт на её вебхуке) вызывает:

```
curl -X POST https://hub.example.com/api/admin/grant -H "X-Admin-Key: КЛЮЧ" -H "Content-Type: application/json" -d '{"nick":"Alex","tier":"plus"}'
```

Игрок в лаунчере увидит новый уровень сразу, без перезапуска. Как связать конкретную платёжку с этим запросом, зависит от неё, и этого я не проверял.

**3. Вручную.** Админ в чате: `/grant Alex pro`, или в консоли: `node server.js tier Alex pro`.

### Первый админ

Зарегистрируйся в лаунчере как обычный игрок, останови сервер и выполни `node server.js tier ТвойНик admin`, затем запусти снова. Дальше всем управляешь прямо из чата лаунчера. Уровень `admin` выдаётся только так или по `ADMIN_KEY`, другие админы его выдать не могут.

### Команды админа в глобальном и локальном чате

`/help`, `/grant <ник> <free|plus|plusplus|pro>`, `/code <plus|plusplus|pro> [сколько]`, `/mute <ник> [минуты]`, `/unmute <ник>`, `/who`. Ответ видит только админ, в чат он не попадает. Заглушенный игрок не может писать в глобальный и локальный чаты (личные сообщения друзьям ему доступны). Обычные игроки команды выполнять не могут: для них `/…` просто текст.

## Уровни, оплата и коды

| Уровень | Что открывает | Цена по умолчанию |
|---|---|---|
| Обычный | готовые темы, свой акцентный цвет | бесплатно |
| Plus | все цвета интерфейса, скругление, шрифт, свой логотип | $0.99 |
| Plus+ | + свой фон-картинка | $2.99 |
| Pro | + анимированный фон из интернета, стильный ник во всех чатах | $4.99 |
| Admin | всё + команды управления в чатах | не продаётся |

Каждый уровень включает предыдущие. Оформление, которое видят другие (ник со стилем и значком), проверяет **сервер**. Локальное оформление (цвета, фон, логотип) проверяет сам лаунчер, поэтому технически подкованный игрок может обойти его, правя файлы у себя. Это косметика только для самого игрока, на других она не влияет.

**Приём денег я в сервер не встраивал:** для этого нужен твой платёжный аккаунт, и это отдельный вопрос налогов и правил Mojang о коммерческом использовании (я не юрист, проверь это сам до запуска продаж). Вместо этого сделан простой и надёжный мост: **код активации**.

1. Ты принимаешь оплату любым удобным способом (Boosty, Ko-fi, Stripe-ссылка, донат и т.д.).
2. Создаёшь код нужного уровня и отправляешь покупателю.
3. Покупатель вводит код во вкладке «Внешний вид», и уровень привязывается к его аккаунту навсегда.

Один код работает один раз. Если у игрока уже такой уровень или выше, код не тратится. В базе коды хранятся только в виде хэшей.

### Как создавать коды и выдавать уровни

- **Из лаунчера**, если у тебя уровень Admin: в глобальном чате напиши `/code plus 5` (пять кодов Plus), `/grant Ник pro`, `/mute Ник 30`, `/unmute Ник`, `/who`, `/help`. Ответ видишь только ты, в чат он не попадает. Админ не может менять уровень другого админа, а `admin` выдаёт только владелец сервера.
- **Первый админ.** Зарегистрируй свой аккаунт, остановь сервер и выполни: `node server.js tier ТвойНик admin`. После этого запусти сервер снова.
- **Из консоли** (сервер остановлен): `node server.js code pro 3`, `node server.js tier Ник plus`, `node server.js users`. Пока сервер запущен, консоль отказывается менять данные, чтобы ничего не потерять.
- **Автоматически, из платёжной системы.** Задай `ADMIN_KEY` и вызывай (например, из вебхука Boosty, Stripe и т.п.):
  ```
  curl -X POST https://hub.example.com/api/admin/grant -H "X-Admin-Key: ТВОЙ_КЛЮЧ" -H "Content-Type: application/json" -d '{"nick":"Alex","tier":"plus"}'
  curl -X POST https://hub.example.com/api/admin/code  -H "X-Admin-Key: ТВОЙ_КЛЮЧ" -H "Content-Type: application/json" -d '{"tier":"pro","count":1}'
  ```
  Ключ длинный и секретный, храни его только на сервере.

### Цены и кнопки «Купить»

Создай файл `data/config.json` (необязательно):

```json
{
  "currency": "USD",
  "prices": { "plus": 0.99, "plusplus": 2.99, "pro": 4.99 },
  "buyUrls": { "plus": "https://boosty.to/...", "plusplus": "https://...", "pro": "https://..." }
}
```

Цены показываются в лаунчере, а «Купить» открывает ссылку в браузере (только `https://`). Нет ссылки для уровня: показывается «по коду». Изменения подхватываются при перезапуске сервера.

## Чаты

- **Личный:** только между друзьями, история хранится (последние 500 сообщений на пару).
- **Глобальный:** все, кто сейчас в сети. Хранится последние 200 сообщений. Не чаще 5 сообщений за 10 секунд.
- **Локальный:** игроки, которые сейчас играют на **одном и том же игровом сервере** (адрес считается без учёта регистра и порта 25565). Живёт в памяти сервера, последние 50 сообщений. Когда игрок не в игре, локальный чат закрыт.
- Админ может заглушить игрока в общих чатах командой `/mute`. В личные сообщения заглушенный писать может.
- Глобальный чат ничем не фильтруется. Для публичного сервера стоит назначить админов-модераторов (`/grant Ник admin` недоступен из чата, нужна консоль).

## Администрирование

Остановив сервер, можно выполнить:

```
node server.js users                       список игроков
node server.js reset Alex новыйпароль      сбросить пароль (кто-то забыл)
node server.js delete Alex                 удалить аккаунт и освободить ник
node server.js tier Alex pro               выдать уровень (free, plus, plusplus, pro, admin)
node server.js code plus 5                 создать коды активации
```

Команды, которые меняют данные, не выполняются, пока сервер запущен (иначе он перезаписал бы изменения). Для работы «вживую» используй команды админа в чате или `ADMIN_KEY`.

**Резервная копия:** достаточно копировать `data/db.json`. Пароли в нём хранятся только в виде хэшей (scrypt), токены входа тоже в виде хэшей.

## Что важно знать

- Уникальность ников действует **среди пользователей лаунчера**. Это не защита самого Minecraft-сервера: человек с другим лаунчером может зайти под любым ником. Чтобы закрыть и это, на игровом сервере нужен режим `online-mode` или плагин авторизации.
- Пароль нельзя восстановить письмом (почты нет), только сбросить командой выше.
- Сообщения хранятся открытым текстом в `db.json` (последние 500 на пару друзей, последние 200 в глобальном чате). Сообщения локальных чатов живут только в памяти и пропадают при перезапуске. Глобальный чат без присмотра: назначь админов, которые могут заглушать нарушителей (`/mute`).
- Если сообщения в глобальном чате могут увидеть дети, подумай о фильтре или о том, чтобы вообще не открывать глобальный чат: сейчас фильтра нет. Предупреди друзей, что чат не шифрован.
- Приглашения работают для **серверов**. Пригласить в свой одиночный мир нельзя.

## Проверка

```
node test.js
```

Запускает сервер на свободном порту и проходит по всему сценарию: регистрация, занятые ники, друзья, чаты (личные, глобальный, локальный), приглашения, уровни и коды, команды админа и заглушение, стиль ника, прокси CurseForge, консольные команды, смена пароля, удаление аккаунта.
